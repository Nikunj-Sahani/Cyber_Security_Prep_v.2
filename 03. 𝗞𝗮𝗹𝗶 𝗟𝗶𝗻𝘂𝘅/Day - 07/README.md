## Introduction to Networking in Linux
Linux networking allows a system to communicate with other systems over a network (LAN/Internet).

- Linux is widely used for network servers, routers, firewalls, and penetration testing systems.
- It provides powerful built-in tools for managing IPs, routing, DNS, and troubleshooting.

### Key Networking Concepts

- **IP Address :-**	Unique number identifying a device on a network

- **Subnet Mask :-** Defines network and host portion of IP

- **Gateway :-**	Device connecting networks (usually router)

- **DNS :-**	Converts domain names to IPs

- **MAC Address :-**	Unique hardware ID of a network card
